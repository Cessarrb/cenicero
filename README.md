# Cenicero

App web para llevar la cuenta de los cigarros que fumás.

- **Hoy:** botón grande +1, conteo del día, hora del último y botón para deshacer. Totales de la semana, del mes y promedio diario.
- **Registro:** barras de los últimos 7 días y lista por día con la hora de cada cigarro.
- **Cajas:** sumás cajas compradas con fecha y precio. Totales de cajas y de gasto por semana y mes, costo por cigarro e historial de cada compra.

Es un solo archivo (`index.html`), sin instalar nada. Los datos se guardan en el navegador del celular (localStorage).

## Usarla

Activá GitHub Pages en *Settings → Pages → Branch: main / root* y abrila desde `https://cessarrb.github.io/cenicero/`. En el celular, "Agregar a pantalla de inicio" para tenerla como app.
